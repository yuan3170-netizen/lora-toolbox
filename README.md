# LoRA 前后期工具箱

> 作者：B站 [@翡翠珍珠排骨](https://space.bilibili.com/3923028) · UID 3923028

一套基于 SDXL 的 LoRA 前后期处理工具（数据准备、打标、查重、LoRA 管理、Loss 曲线分析）。

如果这个工具帮到了你，欢迎来 B 站点个关注 ⭐

## 功能

| Tab | 功能 |
|---|---|
| 🚀 一键流水线 | 尺寸统一 + 统一命名 + 查重 + WD 打标 + Tag 精修 |
| 🖼️ 尺寸统一 | 单步缩放 / 画布填充 |
| 🏷️ WD 打标 | WD Tagger 批量打标（支持 GPU） |
| ✏️ Tag 编辑器 | 标签批量替换 / 删除 / 统计 |
| 📦 LoRA 管理器 | 分组 / 元数据 / 批次 / **Loss 曲线** / 标记 / 清理 / 归档 |
| 📚 数据集 | 训练集管理 / 触发词提取 / 关联 LoRA |
| 🛠️ 图片工具 | 标签统计 / 相似图片查找 / 手动分类 |

主要面向 SDXL LoRA 的处理流程，大部分功能同样适用 SD1.5。

## 下载与使用

### 方式 1：完整版（推荐小白）

1. 到 [Releases](../../releases) 页面下载最新版压缩包
2. 解压到任意文件夹（**路径不要有中文**）
3. 双击 `启动.bat`，即可使用

### 方式 2：源码版（适合开发者）

1. 克隆本仓库
2. 双击 `启动.bat`，脚本会自动：
   - 检测并安装 VC++ 运行库
   - 下载并安装便携 Python
   - 安装依赖（约 3-10 分钟，取决于网速）
   - 提示下载 WD 打标模型（约 1.2 GB）

**首次运行**会花 5-30 分钟，请耐心等待。

---

## ⚠️ 首次使用前：下载 WD 打标模型

WD 打标功能需要模型文件（约 1.2 GB），不包含在程序里。

脚本首次运行会**自动下载**（从 hf-mirror.com 镜像站）。
如果下载失败，手动下载：

1. 打开：https://hf-mirror.com/SmilingWolf/wd-eva02-large-tagger-v3/tree/main
2. 下载这两个文件：
   - `model.onnx`
   - `selected_tags.csv`
3. 放到：`models\wd-eva02-large-tagger-v3\`

最终结构：
LoRA前后期工具箱
└── models
└── wd-eva02-large-tagger-v3
├── model.onnx （约 1.17 GB）
└── selected_tags.csv （约 250 KB）

## GPU 加速

**默认 CPU 模式**（够用，打几十张图很快）。

如果有 NVIDIA 显卡并想用 GPU：
1. 装 NVIDIA 驱动 + CUDA Toolkit 12.x + cuDNN 9.x
2. 打开 cmd，cd 到工具箱目录：
3. 重启工具箱 → WD 打标面板的 GPU 勾选框自动亮起

没装 CUDA 也没关系，程序会自动降级到 CPU 模式，不会崩溃。

## 常见问题

**Q: 为什么启动这么慢？**
A: 首次运行需要下载 Python + 依赖 + 模型，总共约 2-3 GB。之后启动秒开。

**Q: 卡巴斯基/360 报毒？**
A: 脚本会调用 PowerShell 下载文件，杀毒软件会敏感。允许即可。

**Q: 训练日志在哪里设置？**
A: LoRA 管理器 → Loss 标签页 → 右下角「⚙ 日志目录」，选你的 `lora-scripts/logs/` 目录。

**Q: 归档的文件去哪了？**
A: LoRA 管理器 → 顶部「📦 归档区」视图 → 扫描即可看到。
